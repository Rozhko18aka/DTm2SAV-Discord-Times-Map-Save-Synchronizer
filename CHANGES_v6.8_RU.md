# DTm2SAV 6.8

- Удаляемые строения теперь показываются во вкладке «Строения» с действием «удалить», исходным ID и координатами.
- Выключенная галочка JSON действительно отключает запись JSON. При подтверждённой перезаписи результата прежний отчёт этого SAV удаляется; посторонний JSON не удаляется.
- Повторный перенос без JSON использует внутренний кэш `%LOCALAPPDATA%/DTm2SAV/baselines`. Файлы .state содержат сжатое исходное состояние карты, привязаны к точной контрольной сумме SAV и проверяются при чтении. Рядом с SAV DTm не создаётся. Для переноса на другой компьютер включайте JSON и копируйте его вместе с SAV. Сам кэш можно удалить; при этом исчезнет возможность автоматического повторного переноса без соответствующего JSON или исходной карты.
- Исправлена проходимость деревьев: пересборка обновляет все доступные слои C/A/B. Непроходимость сохраняется при наложении других декораций, стоимости прохода перекрывающихся объектов складываются относительно исходного типа ландшафта.

На сохранённом примере пользователя восстановленные свойства всех затронутых клеток совпали с исходным игровым SAV во всех трёх слоях, включая непроходимые деревья. 194 автоматических теста прошли. В настоящем Tk-интерфейсе проверены отображение удаления строения №32, отключённый JSON, повтор через кэш, оба режима сохранения, иконка и развёрнутое окно. Проверка непосредственно в игре не выполнялась.

Обновите исходники и пересоберите EXE из этой версии. Новый модуль conversion_state.py должен находиться рядом с остальными .py при запуске или сборке; PyInstaller включает его автоматически. Ранее созданные SAV с неправильной проходимостью нужно создать заново из сохранения до ошибочного переноса: одно обновление программы не исправляет старые файлы.

Предыдущие исправления сохранены. Сведения о поведении галочки JSON в старых CHANGES являются историческими; актуально описание 6.8.
