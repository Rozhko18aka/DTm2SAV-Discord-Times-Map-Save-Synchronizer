# DTm2SAV 6.9

- Повреждённые, недоступные или неподходящие данные JSON/кэша больше не отменяют анализ сами по себе. Программа пробует JSON, кэш по контрольной сумме SAV, затем выбранную исходную DTm. Причина пропуска показывается в журнале. Если ни один источник не подходит SAV, сохраняется понятная ошибка; проверка формата не обходится.
- JSON проверяется по структуре и типам полей. Массивы, null, числа, повреждённый текст и неверные поля baseline обрабатываются без внутренней ошибки AttributeError. При сохранении без JSON посторонний или повреждённый существующий отчёт не удаляется: нужно выбрать другое имя результата.
- Во вкладке строений отображаются изменения параметров, текста, координат и перенумерация существующих строений, наряду с добавлением и удалением.
- Изменение уже затронутого игрой события больше не попадает в блокировки. Его запись и тексты сохраняются из SAV. Попытка удаления такого события также пропускается с сохранением прогресса. Необходимая перенумерация ссылок при изменении объектов продолжает выполняться. Пропущенные номера отражаются в отчёте skipped_progressed_event_ids; самостоятельные пропущенные правки не считаются применёнными. Исходное состояние для повторного переноса учитывает фактический результат.

Проверка: 200 тестов прошли. Отдельно проверены испорченный JSON/кэш, резервный переход на правильную DTm и отказ для неправильной карты, побайтная сохранность затронутых событий, отображение изменений строений в Tk, оба режима JSON, удаление объектов и совпадение проходимости деревьев с нативным SAV. Проверка непосредственно в игре не выполнялась.
