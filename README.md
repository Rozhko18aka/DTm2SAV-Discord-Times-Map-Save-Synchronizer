# DTm2SAV

**Discord Times Map/Save Synchronizer**

DTm2SAV — утилита для переноса изменений из файлов карт `.DTm` в существующие сохранения `.SAV` игры **Discord Times**.

Программа позволяет редактировать карту и применять изменения к уже начатому прохождению, сохраняя текущее игровое состояние там, где это возможно.

## Возможности

DTm2SAV поддерживает синхронизацию:

- армий и состава отрядов;
- характеристик юнитов;
- артефактов и заклинаний;
- строений;
- гарнизонов;
- казарм;
- рынков;
- святилищ;
- событий;
- связанных Army ID и Building ID;
- runtime-структур сохранения.

Программа использует игровые данные непосредственно из установленной игры:

`Rus_Units.ini`  
`Rus_Artefacts.ini`  
`Rus_Spells.ini`  
`_Global.ini`  
`Graphics/Objects/Objects.ugs`

Благодаря этому DTm2SAV может работать с изменёнными характеристиками и модифицированными игровыми данными.

Если параметры отличаются от протестированного стандартного профиля Discord Times, программа показывает предупреждение, но позволяет продолжить синхронизацию.

## Установка

Поместите `DTm2SAV.exe` в корневую папку Discord Times.

Пример:

```text
Discord Times/
├── DTm2SAV.exe
├── Rus_Units.ini
├── Rus_Artefacts.ini
├── Rus_Spells.ini
├── _Global.ini
└── Graphics/
    └── Objects/
        └── Objects.ugs
```

При отсутствии необходимых игровых файлов приложение сообщит об ошибке и предложит запускать DTm2SAV из папки игры.

## Важно

Перед изменением сохранения рекомендуется сделать резервную копию `.SAV`.

Проект не является официальным инструментом разработчиков Discord Times.
