# DTm2SAV-Discord-Times-Map-Save-Synchronizer
DTm2SAV — Discord Times Map/Save Synchronizer — утилита для переноса изменений из файлов карт .DTm в существующие сохранения .SAV игры Discord Times.  Программа позволяет изменять карту в редакторе и применять эти изменения к уже начатому прохождению, сохраняя текущее игровое состояние там, где это возможно.
