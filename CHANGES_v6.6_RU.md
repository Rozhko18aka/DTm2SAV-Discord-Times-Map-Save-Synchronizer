# DTm2SAV 6.6

Исправлено добавление армий/строений одновременно с изменением уже затронутого игрой события: при добавлении в конец списков независимые правки событий теперь проверяются отдельно. Перенумерация существующих объектов по-прежнему проверяется общей группой.

Исправлен повторный перенос частичного результата. Файл `имя.sav.sync.json` хранит точное исходное состояние карты для следующего переноса. Оставляйте его рядом с SAV с тем же именем. Приложение проверяет контрольные суммы и автоматически использует это состояние вместо выбранной исходной DTm. Соседняя DTm не создаётся. Галочка JSON теперь управляет подробным отчётом; минимальные данные повторного переноса сохраняются всегда.

Если SAV впоследствии перезаписан самой игрой, контрольная сумма меняется: старый JSON не применяется. Для такого SAV нужна соответствующая фактическому состоянию исходная карта. Автоматическое восстановление происхождения произвольных старых SAV пока не поддерживается.

На предоставленных файлах ошибка v6.5 воспроизведена побайтно. Из уже созданного `Тихая пристань_updated.sav` восстановлена точная промежуточная карта; новый результат содержит 32 строения, 22 армии и 93 события. Блокируются только параметры и текст события №1, уже затронутого игрой. Исправленное сохранение и его JSON выданы отдельным ZIP. Распакуйте оба файла в Saves. Исходники в папке игры не изменены.

При повторном переносе выбирайте новый SAV и нужную изменённую DTm. Для поля исходной DTm можно оставить `Тихая пристань2.DTm`: при наличии соответствующего JSON приложение возьмёт точное исходное состояние из него. Для возврата к прежней карте укажите `Тихая пристань.DTm` в поле изменённой карты; ограничения сохранения прогресса продолжат действовать.

Установка: замените содержимое папки приложения файлами из `dtm2sav_fixed`. Запуск `run_quest_sync_gui.bat`. Если используете EXE, пересоберите из новых исходников; старый EXE не обновляется заменой .py. Нужен Python с Tkinter для запуска исходников или сборки. Игровые INI и Graphics/Objects/Objects.ugs должны находиться рядом с приложением в папке игры.

Проверки: 185 автоматических тестов, реальные входные файлы пользователя, повторный прямой/обратный анализ, Tk-интерфейс. Проверка в самой игре не выполнялась.

Все изменения 6.5 сохранены: таблицы клеток армий, имя внутри SAV, иконка, развёрнутое окно, 50×50, удаление событий. Подробности в исторических CHANGES_v6.5_RU.md и CHANGES_v6.4_RU.md.
