# DTm2SAV v6.3.1

- Установлена предоставленная Icon.png без изменения рисунка. PNG сохраняется в исходном размере 79×79; дополнительно подготовлен ICO с размерами 16, 24, 32, 48 и 64 пикселя.
- Приложение в Windows изначально открывается развёрнутым на весь рабочий экран (состояние zoomed). Кнопки свернуть/закрыть и панель задач остаются доступны.
- Иконка применяется к окну; команда сборки PyInstaller дополнена --icon и включением папки assets, чтобы EXE также имел новую иконку.
- Проверен запуск настоящего Tk-интерфейса в невидимом тестовом окне: загрузка PNG/ICO и состояние zoomed. Проверена компиляция изменённого Python-модуля.

Содержимое папки dtm2sav_fixed, включая assets, нужно поместить в корень игры. Запуск: run_quest_sync_gui.bat или python dtm_to_sav_gui.py. Архив содержит исходный проект, готовый EXE в него не входит.

Все исправления v6.3 и поддержка 50×50 сохранены. Алгоритмы преобразования в v6.3.1 не менялись. Их предыдущий прогон: 148 успешных тестов, включая предоставленные игровые файлы.

Восемь подтверждённых проблем из аудита исправлены либо закрыты безопасным отказом при конфликте прогресса. Это не гарантия отсутствия остальных ошибок. Пересборка гарнизона с игровыми потерями/ранениями блокируется, а не выполняется с потерей прогресса. Нативная загрузка результата в игре не проверялась; экспериментальные ограничения неизвестных runtime-полей, footprint и визуального смешивания остаются. Подробности — CHANGELOG_v6.3_RU.md.
