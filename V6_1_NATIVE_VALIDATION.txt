Discord Times QuestSync - live game-data validation v6.1
Date: 2026-09-20

Behavioral change
-----------------
The GUI now refuses to start unless all required game-data sources exist beside
the application:
  Rus_Units.ini
  Rus_Artefacts.ini
  Rus_Spells.ini
  _Global.ini
  Graphics\Objects\Objects.ugs

These files are parsed at startup. The live catalog drives unit stats, level-up
values, Cost/CostMultipler/CostGoldDiv, artifacts, spell modifiers and
CostRecruitDiv. The embedded army_catalog.json is only the tested reference.

Profile compatibility
---------------------
Live gameplay fields are compared to the embedded reference while cosmetic
name/description/icon fields are ignored. Changed Unit/Artifact/Spell IDs and a
changed CostRecruitDiv are reported to the user. Saving remains enabled.

For an affected changed combination, byte-certified exact native profiles are
not reused. Reconstructed formulas are used instead, including in production
strict mode. Unchanged combinations retain the old strict native-profile rules.
