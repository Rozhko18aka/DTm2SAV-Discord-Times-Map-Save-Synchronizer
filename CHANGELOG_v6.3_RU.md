# DTm2SAV v6.3 — исправления и карты 50×50

Дата выпуска: 23 сентября 2026.

Исправленная версия на основе DTm2SAV v6.2 postreview hotfix1. Архив содержит исходники Python, встроенные справочные профили и тесты. Игровые файлы и сохранения в архив не включены.

## Установка и запуск

1. Распакуйте архив.
2. Скопируйте содержимое папки `dtm2sav_fixed` в корневую папку Discord Times, рядом с `Rus_Units.ini`, `Rus_Artefacts.ini`, `Rus_Spells.ini` и `_Global.ini`. Сохраните подпапки.
3. Файл `Graphics/Objects/Objects.ugs` должен оставаться на своём месте.
4. Запустите `run_quest_sync_gui.bat` либо `python dtm_to_sav_gui.py`. Нужен Python 3.10+ с Tkinter; код проверялся на Python 3.13.
5. Для результата выбирайте отдельное имя SAV.

EXE в этот выпуск не входит. Исходные файлы в папке вашей игры во время работы над выпуском не изменялись.

## Исправления

- **Прогресс армий.** Потери и изменившиеся уровни больше не мешают несвязанным правкам. Для сохранённых армий проверяется фактический состав SAV; целевой состав DTm требуется для намеренно пересобранных армий.
- **Гарнизоны.** Изменение защиты или добычи больше не должно восстанавливать погибших и лечить раненых. Если пересборка затронула бы существующий прогресс, операция останавливается с объяснением. Несвязанные изменения здания сохраняют его гарнизон побайтно.
- **Командир и бойцы.** При смене ролей обновляются соответствующие поля, а HP и прочий сохраняемый прогресс остаются у своего персонажа. Проверка результата выявляет неверные флаги ролей. Неоднозначное перераспределение экипировки существующих бойцов блокируется.
- **Координаты.** X и Y объединяются как одна позиция. Runtime и клеточная таблица используют одно правило. Занятая целевая клетка вызывает понятную ошибку; создаваемые маркеры проверяются после сборки.
- **Текущие INI.** Изменённые характеристики юнита больше не смешиваются со старой вычисляемой силой/v1/v2 из SAV-шаблона. Несовместимые изменённые эффекты также не используют старую силу шаблона.
- **Ограниченная распаковка.** Размер каждого блока SAV, включая последний, ограничен 64 KiB. Проверяются объявленный размер, завершённость BZip2, отсутствие добавочных потоков и превышение размера RLE. Лимиты: сжатый SAV 128 MiB, распакованный SAV 256 MiB, DTm 64 MiB; стороны карты — не более 1024 клеток. Последнее является защитным пределом, а не обещанием поддержки всех размеров.
- **Защита входных файлов.** Выходной SAV и JSON-отчёт не могут совпадать с исходным SAV, обеими DTm и известными используемыми ресурсами игры, в том числе через файловые ссылки. Проверяется политика перезаписи отчёта. Публикация без разрешённой перезаписи не затирает файл, появившийся после предварительной проверки.
- **Ошибки отчёта.** Если SAV создан, но последующая запись JSON не удалась, возвращается частичный успех. GUI прямо сообщает «SAV создан, отчёт не записан». Заранее обнаруживаемые коллизии путей отклоняются до записи SAV.

## Поддержка 50×50

Добавлен отдельный профиль бинарного расположения для MapLDV V.4 50×50 по предоставленному нативному сохранению «Тихая пристань». Исправлены граница блока сетки, расположение C/A/B, визуального слоя, ландшафта и таблицы объектов. Добавлен профиль поиска для карт без объектов-якорей. Существующие профили 100×100 и 200×200 сохранены.

Поддержка не сводится к снятию проверки размера: проверены записи событий, здания, фонари, координаты армий и редактирование ландшафта. Для 50×50 использованы отдельные базовые значения слоёв проходимости, согласованные с предоставленным SAV. Неподходящая граница/геометрия отвергается, а не угадывается.

## Что показали ваши файлы

После распаковки «Тихая пристань.DTm» и «Тихая пристань2.DTm» имеют одинаковую длину 133869 байт и отличаются только байтом по смещению `0x124` (292): `0 → 1`.

Изменений событий, армий, зданий, фонарей, декораций, ландшафта и текстов между ними нет. Указанный байт заголовка не интерпретируется и не импортируется этой версией; его смысл не выдумывался. Поэтому конверсия между этими двумя файлами закономерно возвращает исходный SAV без изменений. Это ограничение описано здесь; отдельное предупреждение в GUI для этого байта в выпуск не включено.

Вместо проверки только такого пустого изменения были созданы временные варианты карты с изменёнными событиями, зданием, фонарём, ландшафтом и координатами армии.

## Проверки

**148 тестов прошли: 117 исходных + 31 дополнительный.** В том числе 8 интеграционных тестов с предоставленными ресурсами и нативными файлами.

Проверено:

- побайтное совпадение payload и упакованного SAV при преобразовании без изменений;
- совпадение результата с исходным SAV при переходе на предоставленную вторую DTm;
- импорт будущего события с сохранением уже затронутого события и динамического хвоста;
- соответствие слоёв C/A/B областям нативных зданий;
- перенос фонаря в нижнюю строку карты 50×50;
- правка здания с обновлением его области и навигации;
- правка ландшафта с обновлением C/A/B, визуального слоя и упакованного ландшафта;
- сохранение позиции армии, переместившейся в игре только по одной оси;
- регрессии потерь/ранений, смены командира, live INI, распаковки и безопасной записи.

Исходный и полученный при преобразовании без изменений SAV:
`19626ef27cf02fbc35d7c34a5ff349256d51dfce2e5ba6baadfca1ee2952e3bc`.

При тестировании Windows-песочница не позволяла работать с каталогами `TemporaryDirectory`, созданными с ограниченными правами. Использован отдельный адаптер, заменяющий только создание временных тестовых каталогов. Исходные тестовые утверждения не менялись. Адаптер приложен в `tools/test_environment_adapter.py`; он сохраняет временные файлы в указанной рабочей папке.

После последнего успешного прогона среда перестала запускать shell-команды из-за ошибки конфигурации Windows-песочницы. В архив включён именно прошедший 148 тестов вариант Python-кода; последующая незадействованная заготовка предупреждения удалена. После этого изменялись документация и упаковка. Архив отдельно проверен по содержимому, CRC и SHA-256 файлов.

## Ограничения

- Загрузка созданных SAV непосредственно в игре не запускалась. Побайтная проверка и структурные тесты не заменяют такую проверку.
- Для новых вариантов footprint, неизвестных runtime-байтов, случайного ассортимента рынков и визуального смешивания декораций остаются ранее описанные экспериментальные ограничения.
- Для сложных конфликтов прогресса выбран отказ до записи результата. Автоматическое слияние раненого/поредевшего гарнизона с новым составом или защитой не реализовано.
- Размеры 100×100/200×200 проверялись имеющимися регрессионными тестами; их старые нативные контрольные файлы в этой сессии не предоставлялись.
- Исторические файлы VALIDATION и POST_REVIEW_FIXES описывают предыдущие версии. Текущий результат указан в этом документе и BUILD_INFO.txt.

## Повторный запуск тестов

Из папки проекта:

```powershell
python -m unittest discover -s tests -v
```

Для всех 148 тестов, включая нативные:

```powershell
$env:DTM2SAV_GAME_DIR = 'D:\FAST\Discord Times ORIGINAL'
python -m unittest discover -s tests -v
```

Без переменной окружения 8 нативных тестов будут пропущены. Для среды с проблемой временных каталогов:

```powershell
python tools/test_environment_adapter.py . --work C:\path\audit-work
```

Каталог нативных файлов читается без изменений. Временные DTm/SAV записываются отдельно.
